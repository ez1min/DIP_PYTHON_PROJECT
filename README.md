# 다시, 공간

대구광역시의 유휴시설을 청년 창업가, 예술가, 소상공인과 연결하는 추천·매칭 웹 프로토타입입니다.

기획 근거는 상위 폴더의 다음 문서입니다.

- `다시_공간_API정의서_요구사항정의서.xlsx`
- `다시_공간_기획발표 (2).pptx`

## 실행 방법

폴더에서 정적 웹 서버를 실행합니다.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

> 지도, 웹폰트, 아이콘과 공간 사진은 외부 CDN을 사용하므로 전체 화면을 보려면 인터넷 연결이 필요합니다.

## 파일 구성

- `index.html`: 화면 구조, 탐색·지도·추천·관리자 뷰와 모달
- `styles.css`: 크림·코발트·오렌지 기반 편집형 디자인 시스템과 반응형 레이아웃
- `data.js`: 대구 9개 구·군 기반 샘플 공간 12건과 공통 코드
- `app.js`: 상태 관리, 검색, 추천 점수, 지도, 관심 저장, 신청, 운영센터 기능

## 아키텍처 파이프라인

```text
사용자 입력
  ↓
index.html (탐색 / 지도 / 추천 / 관심공간 / 관리자 화면)
  ↓
app.js (필터링, 매칭 점수 계산, 화면 렌더링, 역할별 액션)
  ├─ data.js (초기 공간·공통 코드)
  ├─ localStorage (관심공간·신청·방문·등록 상태 유지)
  └─ Leaflet + OpenStreetMap (지도와 공간 마커)
  ↓
카드·상세·추천 결과·관리 대시보드 갱신
```

실제 FastAPI/PostgreSQL 백엔드를 붙일 때는 `data.js`와 `localStorage` 입출력 부분을 요구사항 정의서의 `/api/v1` REST API 호출로 교체하면 됩니다. 화면과 도메인 흐름은 그대로 유지할 수 있도록 분리했습니다.

## 주요 사용자 흐름

```text
공간 탐색 → 복합 필터 → 상세 확인 → 관심 저장 → 방문 또는 이용 신청
맞춤 추천 → 용도·지역·예산·면적 입력 → 점수 계산 → 추천 이유와 순위 확인
운영센터 → 등록 공간 현황 확인 → 공간 상태 변경 → 공공데이터 동기화
```

프로토타입 데이터는 브라우저에 저장됩니다. 초기 상태로 되돌리려면 해당 사이트의 로컬 저장소를 삭제하면 됩니다.
